# Minji 브랜딩 보정 명세

## 목표

잘못 들어간 `minjae.log` 및 `민재` 표기를 실제 이름인 Minji 기준으로 바로잡는다.

## 변경 범위

- 사이트 브랜드와 문서 제목을 `minji.log`로 통일한다.
- 작성자 표시를 `Minji`로 통일한다.
- 헤더, 푸터, 404, 노트·프로젝트·그래프 페이지 메타데이터를 함께 수정한다.
- README와 향후 구현 기준이 되는 상위 계획의 이름도 수정한다.
- 기존 기능, 콘텐츠 구조, 레이아웃, 접근 정책은 변경하지 않는다.
- Sites가 허용하는 범위에서 프로젝트 표시 이름과 공개 주소도 Minji 기준으로 정리한다.

## 검증

- 저장소에서 잘못된 이름이 더 이상 사용되지 않는지 검색한다.
- 타입 검사, 테스트, 프로덕션 빌드를 실행한다.
- 검증된 커밋으로 새 Sites 버전을 저장하고 배포한다.
